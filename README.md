# Autumn-Mini-Game-Arcade
This is a collection of cute mini-games fall themed!

# Featured Games:

- Leaf Catcher:
Catch the falling autumn leaves before time runs out! Don't let the leaves reach the ground!

- Memory Match
Challenge your brain with a quick puzzle and find the matching autumn pairs!

- Apple Bobbing
Click and catch the apples before they disappear!

# Code
- HTML: Used for the structure and canvas layouts
- CSS: Used to style the project and make responsive grid layouts
- Javascript: Used for the game logic
